# 七年 · 人生中台

七年就是一辈子。课程与专注、复盘、账本、修炼、里程碑、人生图书馆，放在一个安静的地方。

纯静态网页，没有服务器、没有依赖、没有统计代码。设计说明见 [docs/设计说明.md](docs/设计说明.md)。

## 本地运行

```bash
npm start
```

打开 http://127.0.0.1:4180 。测试：`npm test`（Node 内置 `node:test` 与 `assert`）。

## 部署到 GitHub Pages

1. 新建一个公开仓库，把本目录推上去。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`。
3. 等一两分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

发布前运行 `npm run release`：统一 `index.html` 与 `sw.js` 的版本号，并重新生成离线缓存清单（`tests/release.test.js` 会检查）。

## 数据与隐私

- **代码里没有任何个人信息**：初始数据是空白模板，第一次打开时填写自己的资料（头像、昵称、个人签名都能改），或者连接同步、从备份恢复取回自己的记录。
- **工作副本**：记录平时保存在当前设备的浏览器里（IndexedDB）。
- **同步**：「设置 → 跨设备同步」连接你自己的**私有** GitHub 仓库，手机和电脑逐条合并，每次同步一个提交。令牌只存在本机，不进备份、不进仓库；公开仓库会被拒绝。
- **档案**：电脑上在「设置 → 数据与备份」选一个备份文件夹，交给网盘客户端自动备份；手机上导出完整档案（.zip）存进网盘。档案是通用格式（CSV、Markdown、原始附件），不依赖本网站也能读，也能原样导回。
- 页面带 `noindex`，不会被搜索引擎收录。

## 目录

```
index.html            页面骨架（严格 CSP，无内联脚本与样式）
styles.css            设计令牌与全部样式（深浅两套主题；专注页为全屏夜景）
theme.js              首屏前应用手动选择的主题
sw.js                 离线缓存（网络优先，3 秒回退缓存）
src/app.js            路由、事件委托、底部面板、提示条、撤销
src/core/             日期、金额、模板转义、存储、数据迁移、zip、GitHub 客户端
src/domain/           纯函数：辈子、课程表、专注与出勤、时间日志、账本（四笔钱）、修炼、图书馆、里程碑、盘点、档案、同步合并
src/pages/            今日、专注、复盘、账本、修炼、里程碑、图书馆、盘点、设置
src/ui/               图标、通用组件、共用面板、附件、备份、同步、主题
tests/                单元测试与发布检查（测试用的人物与课表都是虚构的）
scripts/release.js    统一版本号并生成离线缓存清单
```

## 约定

- 按数据变化的尺寸写成 `data-vars="w:42%"`，挂载后设为 CSS 变量（CSP 禁止内联 style）。
- 可交互元素用 `data-action` / `data-input` / `data-change` / `data-form`，由 `app.js` 统一委托给当前页面或共用面板。
- 每次记录在案的改动都进撤销栈：提示条“撤销”、Ctrl/⌘+Z。
- 深色令牌写在两处（手动选择与跟随系统），`tests/release.test.js` 会检查一致。
- 不新增外部依赖、网络字体、统计或埋点；不在代码、测试、文档里写入任何真实个人信息。

## 快捷键

今日与复盘页：`←` `→` 切换日期，`T` 回到今天，`G` 跳到某一天。专注页：`Esc` 退出。手机上左右轻扫切换日期。
