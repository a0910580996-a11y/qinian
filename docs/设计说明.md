# 七年 · 人生中台 —— 设计说明

> 它存在的唯一理由：帮使用者更好地工作和生活。

## 模块

| 模块 | 做什么 |
| --- | --- |
| **今日** | 按课程表显示当天的课，连续同课合并成一段、标出段内课间；‹ › 切换日期，键盘 ← → / T / G，手机左右轻扫；点日期可以输入 `10.20`、`下周三`、`+7`、`15号` 直达。每段课可以点进专注页 |
| **专注** | 全屏的表盘：一圈就是一节课。一段课签到一次、签退一次，不签到算没上；暂停只停有效时间，墙上时间照走；段内课间自动不计时；下课自动签退，到下一节自动换内容。课间画面亮成晨光，给走一走、晒太阳、打水、颈部操、远眺之类的建议。出勤率、课堂有效率一目了然；也可以开不跟课表的自由专注 |
| **复盘** | 时间日志：一行一件事（`07:10-08:00 早读`、`45m 短视频`），实时解析成 24 小时色带与分类时长；可以按签到记录或课程表起草。感恩日记，每天三件 |
| **账本** | 流水 / 现金流 / 四笔钱 / 资产负债。四笔钱借鉴有知有行：活钱（3–6 个月生活费）、保险、稳钱（1–3 年内要用）、长钱（3 年以上不用），按顺序给出“下一步”，还能“分一笔钱”；本月可支配 = 收入 − 固定开销；负债账户；财务体检 |
| **修炼** | 立下这辈子要练的一门技能，记录刻意练习的有效时长；累计只增不减；八个境界路标通往一万小时；按年度的热力图 |
| **里程碑** | 一生的色带：几辈子分段、段间留缝；目标 → 子目标 → 项目的树；截止日跨到下一辈子时显示“延续至下一辈子” |
| **人生图书馆** | 残卷（句子）、心法（文章）、秘籍（书籍）、演武（视频）、琴谱（歌曲），名字可改；永久编号；可附原始文件；“用上了”记一笔，生成实践热力图与复利榜 |
| **盘点** | 人生资产负债表：注意力 → 时间 → 金钱 → 身体 → 自学 → 积累 |

## 架构

- **纯静态、零依赖**：原生 ES Modules，没有框架、没有构建步骤。
- **分层**：`src/domain/` 是纯函数，可以在 Node 里测试；`src/pages/` 只负责渲染与交互；`src/core/` 是日期、金额、模板转义、存储、zip、GitHub 客户端。
- **一切可撤回**：每次改动前留快照；提示条“撤销”、Ctrl/⌘+Z 连续撤回。
- **安全**：严格 CSP；所有用户内容经转义输出；附件链接只放行 http(s)。

## 存储：按几辈子的尺度

平台会消失，靠得住的只有**开放格式 + 多份自己掌控的副本**：

| | 放哪 | 为什么 |
| --- | --- | --- |
| **程序** | 公开的 GitHub 仓库 + Pages，可离线使用 | 程序可以随时换；代码里没有任何个人信息 |
| **工作副本** | 浏览器（IndexedDB） | 快、随手可记；但会被清理，所以只是副本 |
| **同步与版本** | 自己的**私有** GitHub 仓库，只放文字数据 | 手机和电脑三方合并；每次同步一个提交，修改历史都在；仓库里同样是能直接读的表格和文字 |
| **档案** | 电脑上的备份文件夹 → 网盘客户端自动备份；每年再拷一份到移动硬盘 | 通用格式；附件只在这里 |

- 档案里：账本 CSV、时间日志/感恩/图书馆/里程碑 Markdown、课堂专注 CSV、附件原件（按编号命名）、`data.json` 与附件索引（可导回）、`历史/` 每天一份快照。
- 同步的合并规则：以上次同步为共同版本；只有一边改了就用那边；两边都改了逐条、逐字段合并；同一个值冲突以正在同步的设备为准；删除也同步。新设备第一次同步以云端为准；两边都有记录时会先问。
- 档案不加密：几十年里忘记密码的风险，比被人看到的风险更大。

## 反焦虑原则

1. **只累加，不清零**：不做连续打卡，断一天不会归零。
2. **只和自己比**：没有排名、没有红线；没记录的日子不算“没做”。
3. **路标代替考核**：一万小时拆成八个境界。
4. **数据太少不推算**：练习记录不满 7 天，不预测何时到一万小时。
5. **颜色克制**：负债用低饱和的赭色；朱砂只给印章与“此刻”。
6. **措辞中性**：“还没写”而不是“未完成”。

## 设计语言

- **纸、墨、一枚朱印**：暖白纸色底、墨色文字、黛绿表示操作与投资、金色只给达成；印章上的字由使用者自己定。
- **专注页**：夜色里的水墨远山，表盘居中；课间画面渐变成晨光。
- **字体**：标题用宋体系（西文 Palatino），残卷用楷体，正文与数字用系统黑体与等宽数字；不加载网络字体。
- **动效**：只在有意义处使用；系统开启“减少动态效果”时全部关闭。
